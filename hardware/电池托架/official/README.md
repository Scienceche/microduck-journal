# 电池方案:官方背板拓展(按原仓库结构)

## 官方结构(从 microduck.step/glb 提取实测)

- 官方电池:**NP-F970**,38.6×20.6×70.8mm,2S 7.4V(顶上 banana_pcb 转接板+锁件)
- **power_support** = 电池舱背板(手册 T05"电池后盖板"),54.5×17×83.5mm,
  两侧 4×M2 螺丝固定(约 ±18.3 处),底部宽法兰,顶部 ±5.4 卡口锁 banana
- 电池塞进躯干腔体,靠背板+左右壳封住——**官方没有独立电池夹**

## 本方案(拓展,不重造)

你的电池 35×38×70(带板),厚 38 = 官方 20.6 的 1.85 倍。舱深不够 →
**官方背板原样打印,加垫块后移**:

| 文件 | 说明 |
|---|---|
| power_support_official.stl | 官方背板(从整机 GLB 提取,3208 三角,可直接打;不用 banana 就不打 banana_locker) |
| spacer_T8/12/16.stl | 垫块 Ø5×Ø2.2 内孔,M2 螺丝穿过;每规格 1 颗,切片时复制 4 份 |
| spacers.py | 参数化(改 SIZES/T 重出) |

**舱深账**:官方可用 28.3mm(20.6 电池+7.7 间隙)。裸电池 38 → 差 9.7 → **T12**;
带保护壳 43.8 → 差 15.5 → **T16**(紧)或改 T18(脚本加一行)。
螺丝换 M2×(T+8)。

## 装配

1. 试装:三种垫块各试,选"装得下且背板不顶出壳轮廓"的
2. 4×垫块套在 4 颗螺丝上(垫块在躯干与背板之间),锁紧
3. 电池(建议裸包+1mm EVA 包裹+扎带,或用 ../battery_case 两件壳)放入,
   线从底部引到 imu 板 J1(建议 XT60→裸线短线)
4. 背板锁回

## 注意

- 背板后移 T 后,顶部 banana 卡口位置也后移——不用 banana 则无影响
- 若背板后移顶到左右外壳内壁,先量内壁到背板的实际净距再定 T
- GLB 提取的网格比原始工程模型略简,垫块/螺丝孔对不上时以实物孔位为准
  钻孔修正(垫块孔 Ø2.2 有余量)

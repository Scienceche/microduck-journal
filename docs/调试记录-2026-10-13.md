## 3. 统一中控 v3（用户需求：一个"全部的"中控，套用现成资产）

**架构**：`duck-panel` 服务重写为 aiohttp（仍 :8080，服务名不变）：

- v2 全部 API 原样保留（IMU/扫描/舵机/姿态库/急停/烧录/系统）
- 仪表台（原 imu-scope @:8081）整个并进同一进程：`/scope/*` 静态、`/ws` WebSocket
  （前端写死 `/ws` 所以挂根路径）、`/api/ports`；复用部署版 `/root/imu-scope/server.py`
  （含 md1 personality + 串口枚举 glob 补丁），前端零修改（iframe 内嵌）
- 前端加「仪表」标签页：进页自动连总线，切走/退后台自动 disconnect
- 新增 `/api/scope_defaults`：自动连接参数的唯一事实来源
- **总线仲裁**：包装 SESSION.connect/disconnect——仪表连接 = 面板 FeetechBus 立即关闭
  且 get_bus() 拒绝新操作（错误信息提示切走仪表页）；断开自动恢复。v2 的 4s 空闲释放保留
- sw.js 缓存名升 v3，`/scope/`、`/ws` 不走 SW 缓存

**本次抓出的三个 bug**：

1. **仲裁自清零**：`Session.connect()` 第一行调 `self.disconnect()`（已被我包装）→ 把刚置的
   scope_hold 清掉 → 面板和仪表同时开串口，采样全撞死（症状：connected=True 但 samples=0，
   面板同时还能读 IMU）。修复：connect 成功后重新 `_scope_hold.set()`。
2. **协议选错 → 全部超时**：dxl 的 sync_read 是双字节地址（Robotis 格式），fee 才是单字节地址
   （飞特格式，我们的 G031 固件）。defaults 发 dxl 时 poll 永远 None（error 为空、samples=0）。
   修复：`/api/scope_defaults` 返回 `PROTO_FEE`（md1 personality 由 Session.connect 从环境变量
   默认拿到，diag 块 124）。**10-11 仪表台能用是因为当时浏览器里手选了 fee**——服务默认值一直是 dxl。
3. **旧 imu-scope 服务抢总线**：其前端一打开就自动连 :8081 → ttyS2 多进程互踩
   （pyserial 报 "multiple access on port"）。修复：`systemctl disable --now imu-scope`
   （文件保留，功能已被 /scope/ 取代）。

**端到端验证**（/root/smoke_v3.py，协议级）：

```
GET / /scope/ /scope/app.js /manifest  全 200
before: imu.ok=True  scope_holds=False
scope streaming: connected=True  samples_in_3s=133   (50Hz 档)
during: imu.ok=False scope_holds=True  err=IMU仪表占用总线（切走仪表页自动释放）
after:  imu.ok=True  scope_holds=False  |q|=1.0
```

**回滚**：板上 `duck_panel_v2.bak.py / index_v2.bak.html / sw_v2.bak.js`；
imu-scope.service 可 `enable --now` 复活（但会和 v3 抢总线，勿同时用）。

## 6. 微信自动发文件（打板 zip → 手机）+ 自动化方法论沉淀

dxl_hub gerber zip 通过**电脑微信自动发到"文件传输助手"**（全程机器操作，手机端查收）。
EDA 在线导入自动化失败后，改走"微信传文件 → 手机嘉立创 app 上传 zip 下单"。

**微信桌面版自动化规律**（首次摸索 ~15 轮，已固化为可复用脚本）：

- 自绘列表/按钮对 a11y `AXPress` 全部无效；`textfield` 的 `setValue` 有效且触发搜索
- 通用点击法：`elements()` 拿 bounds（全局坐标）→ 按 `(elCenter - winOrigin) × raster/window`
  换算光栅坐标 → `left_click {strategy:"event"}`；光栅尺寸解析 PNG IHDR 头
- "选择文件"是独立顶层窗口（大号）；路径错误弹**小号**同名原生错误框（AXPress 有效）
- `event` 策略要求目标前台，先 `getState` 验 active；中文键入会被 IME 吞 → 搜索词用
  setValue、文件路径用纯 ASCII type
- 成品：`工具/computer_use/wechat.mjs`（`sendFileToWeChat({chat, filePath})` 一次调用）
  + `工具/computer_use/README.md`（速查表，含"EDA 类自绘应用不值得自动化"结论）

**通用教训**：a11y bounds 优先于 vision 猜坐标；验证用树不用眼；
长会话防幻觉——只信最新一条工具输出，每个动作必须有真实观察佐证。

# 电池方案:2S 软包 35×38×70(含保护板,底面 XT60+JST 出线)

本地文件:`硬件资料/电池托架/`(仓库镜像 hardware/电池托架/)。

## 结论(2026-10-18)

- **电池壳**:两件式(壳体+摩擦盖)。软包全包裹,内腔每边 0.5mm + 顶部 3.6mm
  膨胀余量;电池坐两侧凸轨(底部 6mm 走线通道,保护板悬空),出线豁口 26×12
  在端墙底部(XT60 整穿);锁带槽开在壳顶+盖裙(对齐,一根带锁两件),只勒壳
  不碰电芯。PETG/0.2 层/免支撑。
- **支架 = 官方背板拓展**(不重造):官方无独立电池夹——NP-F970(38.6×20.6×70.8)
  塞躯干腔,靠 power_support 背板(54.5×17×83.5,两侧 4×M2)+外壳封仓。
  本电池厚 38 → 舱深差 9.7(裸)/15.5(带壳)mm → **官方背板原样打印 + 4×垫块
  后移**(T8/12/16 参数化,裸电池选 T12,带壳 T16/18,螺丝换 M2×(T+8))。
- 官方件已从 Downloads/microduck.glb 提取:mm 级 STL(official/ 子目录),
  含背板/banana 锁件/NP-F970 实测尺寸。

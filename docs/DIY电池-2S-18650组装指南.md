# DIY 电池指南：2S 18650 自组包（NP-F550 舱位）

> 2026-11-08 起草。前提：外壳/支架套用 **NP-F550** 电池舱（公称约 38.2 × 20.5 × 70.5 mm，宽×厚×长）。
> 工具：电烙铁 + 万用表（无点焊机）。充电：待购（见 §5，注意**保护板 ≠ 充电器**）。
> 关联文档：`电池方案-3D打印件.md`（旧 35×38×70 成品软包方案）、`新手接线与装配.md`（J1 上电流程）。

## 1. 方案一页纸

> **2026-11-08 转向**：外接口改为 **NP-F550 全 dock 形态**（背面触点照抄真电池几何、
> 座充直充、鸭子腔内触点供电、零插拔），设计见 **§10**；本节以下与 §4–§7 的
> 内部组装工艺（电芯/PCM/接线/验收）不变，仅对外接口按 §10 替换。

- **电芯**：2 × 18650 并排、一正一反，底部镍片跨桥串联 → 2S
- **保护**：2S 带平衡 PCM（同口），塞在端部空位
- **输出**：XT60（动力）+ JST-XH-3P（平衡/充电），长边端部出线
- **外形**：2 节并排 66 × 38.4 × 19.6 mm（含热缩），正好贴 NP-F550 舱，**官方背板无需垫块**
- **容量/放电**：2500–3500 mAh；选 ≥10A 放电档次（见 §4）
- **质量**：约 95–110 g（比旧 35×38×70 软包轻 ~60–90 g → **仿真质量要同步改**，见 §8）

## 5. 保护板与充电器（澄清你看到的"8A 保护板平衡充"）

- 那种 ¥3–6 的"2S 8A 带平衡"小板是**保护板（PCM）**：只负责过充/过放/过流保护和充满时平衡。**它不能给电池充电**。
- 8A 够不够：持续电流被 F1 保险丝限制在 5A 以下，8A 不会和保险丝打架；但起身/急停瞬时大电流**可能触发 PCM 过流保护→鸭子瞬间断电跪倒**（旧成品包自带 PCM 通过过起身测试，同档应可）。**同价优先买 10–15A 版**。
- **下单前问卖家的 4 个问题**（2026-11-08 起约束所有候选板）：
  1. 过充保护电压 **必须答 8.4V（4.2V/节）**——注意"2串 7.2V"字样有歧义：可能是锂电标称电压写法（充电仍 8.4V，可用），也可能是**磷酸铁锂板**（充电截止 7.2V、过放 ~5.0V，装锂电=长期充不满且会过放，**禁用**）。卖家答不出 8.4V 就换。
  2. 过放保护电压：应在 **5.4–6.0V（2.7–3.0V/节）**。
  3. 是否**带平衡**（3P 平衡焊盘/口）——图上"3P"字样需确认；不带也能用（B3 走直连平衡口充、PCM 只做主路保护），但同价优先带平衡版。
  4. 板子**外形尺寸+元件最高点**：要 ≤30×17×4mm 才能平塞端部 5mm 隙；超长集成条板（~50mm）则改在打印壳端部做凸包仓装板。
- **候选板判定（2026-11-08，优宝科"2串 5A-8A"集成板，34.4×13.4mm，焊盘式）**：
  - ✅ **三元（锂电）参数表**：过充 4.25±0.05V/节（整组兜底 8.5V；正常充电截止由充电器 8.4V 完成，PCM 只做兜底——正常设计）、过放 2.80±0.1V/节（整组 5.6V ✓ 落在 5.4–6.0 区间）→ 上一张图的"7.2V"字样确认为标称写法，**不是磷酸铁锂板**，歧义解除
  - ✅ **尺寸 34.4×13.4mm 可平塞端部空隙**（34.4<38.2 宽、13.4<20.5 高、含元件约 3.5–4mm 厚 < 5.3mm 隙）；元件面朝舱壁方向，**不得贴电芯钢壳**
  - ❌ **均衡功能 NO** → JST-XH 平衡线**不经保护板，直焊电芯三抽头**（见 §6 接线图）；B3 从平衡口充电成为主充电路径，PCM 只做主路兜底
  - ❌ **温控 NO** → §7-7 首充人工测温条款为强制项
  - ⚠️ **过流=50±15mV 压降检测制**，实际动作电流=50mV÷MOS 内阻（卖家标 5A–8A，精确阈值未知）；若上机后**起身中途突然断电**，即判定 PCM 过流动作 → 记录现象换 10–15A 板复测
  - ✅ 自耗电 ≤35μA（整月约 25mAh，可忽略）；短路保护有（250/960μs）
- **路线决策（2026-11-08，用户确认）：保护电路一律买成品板，不自制**。
  理由：保护板是电池包唯一安全件，成品板自带厂家标定（过流阈值/延时/解除电压），
  自制省不下钱（打样+元件+验证设备 ≫ ¥6）却引入四项保护行为全验证负担；
  曾评估自制无源整合载板/完整保护板两条 DIY 路线，均放弃。
  备件策略：**一次拍 3 块**（装 1 备 2）；若日后想要带平衡版，同样买成品而非自制。
- 必须选**同口**（充放电同一对 P+/P−）+ **带平衡口（JST-XH 3P）**。
- 充电器选型矩阵（2026-11-08 更新，含"NP-F550 智能座充"判定）：

  | 路线 | 价 | 速度 | 节级平衡 | 判定 |
  |---|---|---|---|---|
  | **B3 平衡充**（插 XH 平衡口） | ¥25–40 | 0.8A，~3.5h | ✅ 每次都平衡 | **必买**，首充必须走这条 |
  | 8.4V/2A 2串智能充（插 XT60 主口） | ¥15–30 | ~1.5h | ❌ | 可选快充件，PCM 兜底在线 |
  | NP-F550 智能座充 | ¥15–25 | 8.4V=1–2A | ❌ | **2026-11-08 起转为主充**（配合 §10 全 dock 电池组：背面触点照抄真电池）；座充无平衡，B3 保留平衡职责 |

  - **组合建议**：日常 XT60 智能充快充，**每隔 3–5 次充电、或量到两节压差 >0.03V 时用 B3 平衡一次**；只买 B3 也完全成立（就是慢）
  - 座充宣传的"9 重保护"均为充电器自身保护，**不含电芯温度感知**，人工测温规矩不变
- 充电电压硬约束：**8.4V 整（4.20+4.20）**，买错成 8.7V/9V 的"2S 充电器"会过充，禁用。
- **充电位置规矩（2026-11-08）：一律抽出电池、在开放瓷面/砖面充，不在鸭壳腔内充电。**
  壳内充电三宗罪：温度摸不到（壳内测温失真，温控板没有）、鼓包/异味看不见、
  充电时鸭子还在总线上（应关机充电）。
- 由此壳设计须满足（对应旧方案"待实测"第 3 条）：
  1. 电池连 XT60 + JST-XH 两个插头**能从壳里顺利抽出/插回**（抽取路径不卡线）
  2. **板侧 XT60 母头转接短线**固定在壳/板上（免拆焊 J1；抽电池时不拽动 J1 焊点）
  3. JST-XH 可做 100mm 延长线（¥2–3）从出线口垂出壳外，抽出前就能目检插头状态

## 6. 连接工艺（电烙铁路线）

**第一原则：永远不直接在钢壳上堆锡。** 热量会烫伤电芯内部隔膜（热失控风险）且钢壳挂不住锡。

- **买"带镍片/焊片"电芯**（淘宝关键词：`18650 带焊片`/`带镍片`/`带线`），只焊镍片引出端。
- 焊接手法：铁温 350–380°C，**单点 ≤3 秒**，粗线预挂锡+少量助焊剂，焊完一个点等镍片不烫手再焊下一个；下面垫木板，旁边放陶瓷碟接锡珠。
- 实在买不到带片电芯：加购迷你点焊机（¥70–120）比裸电芯直接焊**安全得多**，不要硬焊钢壳。

### 接线图（两节并排，B 节倒置）

```
CELL-A（正立）                          CELL-B（倒置）
  顶：＋ ──18AWG──→ PCM B+               顶：− ──18AWG──→ PCM B−
  底：− ←═══镍片跨桥(串联)═══→ 底：＋
            ├─细线→ PCM 中点感测脚(BM)（逐节 4.25V 过充检测靠这根，必须接）
            └─26AWG→ JST-XH ②黄（与 BM 同点分两线即可）

PCM P+ → XT60 红（+）        PCM P− → XT60 黑（−）
JST-XH-3P 平衡抽头（本板无均衡功能，直抽电芯、不经 PCM）：
  ①黑 = 总负（B 节顶）   ②黄 = 跨桥中点   ③红 = 总正（A 节顶）
（PCM 具体脚位以丝印为准；上机前必按 §7-3 实测三脚电压）
```

### 布局与装配顺序

1. 配对检查（§7-1）→ 2. 电芯各自套绝缘（青壳纸/PET 圈，至少盖正极防爆阀一圈）→
3. 焊底部跨桥（镍片，两电芯并排贴紧）→ 4. 焊顶部两根 18AWG 到保护板 B+/B− →
5. PCM 用青壳纸包好后**塞端部空位**（70.5−65.2≈5mm 端隙，板子选 ≤30×17×4mm）→
6. 焊 P+/P− 出 XT60、平衡口引 JST-XH → 7. 排线折叠平整，无尖锐锡点朝电芯 →
8. 整体套热缩管收束 → 9. **塞 NP-F550 舱试装**（§7-5）。

塑料电池盒（2×18650 串联盒）**不建议**：盒厚 ≈20mm 再叠 PCM 超出 20.5mm 舱深。

## 9. 安全红线

- 充电**永远人工看护**，不放沙发/床上/易燃物上，充满即拔；**不在封闭壳/腔内充电**（见 §5 充电位置规矩）
- 镍片/锡珠/工具不得横跨两极；焊接前摘掉金属手表/戒指
- 电芯严禁短路、过充（>4.25V/节）、过放（<2.5V/节）、挤压穿刺、靠近火源
- 鼓包、异味、发热异常 → 停用，移到室外水泥地隔离
- 组装全程 PCM 未接好前**不接鸭子**；上机前必过 §7-3/7-4 极性核对

## 10. NP-F550 全 dock 版设计（2026-11-08 定向，当前主线）

> 决策：电池组做成 NP-F550 形态克隆。座充（8.4V=1–2A，已判✅）转为主充，
> 鸭子腔内触点弹片供电，滑入即用、滑出即充，零插拔。
> 前半文档的飞线工艺（§4–§7 内部部分）全部沿用，本节只改"对外接口"。

### 10.1 架构

- 内部不变：2×18650 并排 + 优宝科 PCM + §6 接线 + §7 验收
- 对外三件（**2026-11-08 晚修订：鸭子侧从"背面触点"改为官方香蕉接口，见 §10.6**）：
  1. **鸭子取电 = 香蕉母头×2**（顶面近端部，间距 33.80mm 照抄 banana_pcb 插头）
     ——香蕉插头是 RC 震动环境标准件，比滑动触点可靠一个量级
  2. **背面触点板（仅充电用）**：几何照抄真 NP-F550，只接座充（静态 1–2A，触点最擅长的场景）
  3. **JST-XH 平衡座**：端面齐平，B3 定期平衡专用
- 能量流：鸭子=滑入→香蕉插头自动咬合；座充=滑出→背面触点入座；零飞线
- **充电永远不在鸭壳腔内**

### 10.4 新增验收（硬门槛，不过关回退混合式：触点只充电、鸭子取电恢复 XT60）

1. **极性复核**：包背面 + 极位置 == 真电池 + 极位置（万用表，双人复核）

3. **振动验收（关键）**：满电装鸭，行走+起身各 ≥3 次，全程 busStatus 电压

### 10.6 香蕉 dock 接口几何（2026-11-08 从 banana_pcb.kicad_pcb 实测，**取代 §10.3 触点块方案**）

来源：`microduck-community-kit/hardware/banana_pcb/`（社区复刻官方电池转接板，KiCad 9）。
官方架构：`电池(香蕉母头) → banana_pcb(竖装电池上方) → dxl_hub → 左右腿/IMU/头`。

| 项 | 实测值 |
|---|---|
| 两香蕉插头孔中心距 | **33.80mm**（J1@129.17,89.25 / J2@162.97,89.25）——母头布局唯一硬约束 |
| 插头规格 | 2.5mm 香蕉头 ×13mm，尾接 1.5mm²（参考 U6068），正常电流 3–5A |

| 极性 | J1 = +（丝印"+"在其旁），J2 = −；J3 = 双 5×3mm 输出焊盘（接下游板） |
| 打样 | 直接用 `banana_pcb/production/banana_pcb.zip` 嘉立创下单，~¥10 |

- **电池包侧母头布局（自定义标准，已按包内空间定死）**：母头开在**顶面近 PCM 端**（该处
  只有端部空隙 5.3mm × 20.5 高，不顶电芯），间距 33.80mm 沿宽度方向，插拔轴竖直向下，
  母头管长 ≤5mm；鸭子侧打印 PCB 定位座来对齐（不用官方背板顶部卡口的绝对位置——
  官方 GLB 里的电池网格是简化件，母头孔根本没建模，照抄无门，自定义即标准）

**外壳到货实测清单**（先量再装，对照下表判适配）：

| 项 | 量什么 | 判据 |
|---|---|---|
| 内腔宽 | 顶面开口净宽 | ≥2×电芯直径：25R 18.4 → ≥36.9；VTC6/P26A 18.5 → **≥37.1**；GA 18.6 → ≥37.3 |
| 内腔厚 | 净高 | ≥18.7（电芯 18.4–18.6） |
| 内腔长 | 净深 | 电芯长 64.9–65.2 + 端部 PCM/母头区 ≥6mm |
| 端部空腔 | 触点块以外净深 | 决定 PCM 与母头井能不能共存（见关卡①） |
| 随壳附件 | 有无触点片/接线柱 | 有则 §10.2 触点几何直接照抄实物 |
| 壁厚 | 顶/底/侧 | <1mm 属正常；>1.5mm 内腔会不够 |

**三个几何关卡（到货实测后定案）**：

1. **端部空腔争夺**：内腔顶净高 ≈18.7 时电芯上方零余量 → PCM 和香蕉母头井**都必须**
   藏在端部空腔里，而 PCM 板 34.4mm 长（横向铺满）与母头间距 33.80mm 是同一片区域。
   解法候选：母头管**外凸成塔**（顶面立 2 根母头管，插拔深度靠管长在壳外解决）/
   PCM 板改立装/换更短 PCM。到货量完端部净深再选。
2. **座充是否容得下母头塔**：母头塔凸出顶面后，包在座充槽里的姿态要试——不兼容就
   换端面水平出针布局（插件轴沿包长轴），鸭子侧定位座跟着改。
3. **鸭腔头部余量**：香蕉塔(~5mm)+banana_pcb 竖板(~7mm) ≈ 电池顶面以上要 **12mm 左右**。
   官方 power_support 高 83.5 vs 电池 70.8，正是留了 12.7mm——**你的打印壳腔顶有没有
   这个余量，量！不够就重打一块加高腔/延长背板。**

**ban 香蕉塔注意**：母头塔位置 = 鸭子侧定位座位置 = banana_pcb 插头位置，三者一根
对齐链，定一个写一个，别各自拍脑袋。

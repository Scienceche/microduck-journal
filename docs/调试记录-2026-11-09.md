## 标定台「校零」按钮失效 bug（已修复部署）

- **现象**：用户点「校零」toast 显示成功，但 TOML 不更新、`→零` 回旧位。
- **定位三步法**：① 同命令直连 socket 成功落盘 → robotd 无罪；② curl 打面板后端 /api/bus 成功 → 后端转发无罪；③ 前端参数对质发现 `J()` 的 `toFixed()` 返回字符串，robotd serde 拒收 `"0.000"`（expected f64）——错误被 toast 闪现吞掉。
- **修复**：`J()` 改返回 `Number(Number(j).toFixed(s))`，capture 参数显式 `Number()` 包裹。已部署验证。
- **守则新增**：跨语言 API 参数必须核对类型契约（JS 字符串 vs Rust f64）。

## run6：站立专家换血（成功）

- **路线**：放弃行走系热启动，从官方站立专家 69u48n8l@9750 热启动 **StandUp-Flat-Backlash**（同谱系 obs 归一化器，无 twist std 陷阱），2048 环境 4000 轮。
- **物理**：STAND3 前倾 HOME + 竖放电池盒 + 936g 全生效（microduck_constants 全局）。
- **启动坑**：rsl_rl `load-run` 基准是实验名目录，跨实验需拷贝 checkpoint 进 `logs/rsl_rl/microduck_stand/`。
- **结果**：
  - **StandUp 主场：稳定帧 94.8%**（h>0.085 & tilt<25°），高度中位 0.118，倾角中位 **7.7°**（run5 是 19°）——**≥90% 站立门槛首次通过**。
  - VelStand 跨任务：起身 60-80%，站立 ~48%（技能不跨任务，预期内）。
- **结论**：站立基因由起点决定——换血立竿见影，与官方"先站后走"路径一致。
